# PasswordManager
A simple, local, password manager to assist with remembering all those random characters!

11/5/26:
Software is functional but is missing quite a bit of ease of use and refinement with some comments in the GUI.py file indicating what I'd like to work on next. As it stands the password manager works and allows users to decrypt an encrypted file via the encryption software found within my Encryption repository, generate passwords for you and use them to make and remove entries in your own personally encrypted password vault.

11/10/26:
Added a feature for the password entry fields that allows the user to show/hide the password as well as a "Clear" button for the generated password field so that, if the user opts to use this password they can then clear the field. 
  -> May be a good feature to add to clear the generated field when users use it with the "Use Generated Password" option while adding a new entry.
